Dominika Bohuslavová

PhD candidate, Theoretical Computer Science · CTU Prague

I publish under my former name, Dominika Draesslerová — both names refer to the same person.

I build compressed data structures for large collections of biological sequences. Genomes from the same species are overwhelmingly similar to one another; my work exploits that redundancy so that a collection can be stored in a fraction of the space and still be queried quickly.

My dissertation is titled Compressed indices for biological sequence collections. The question I keep coming back to is a practical one: how much can we compress a collection before the answers we get out of it start to degrade — and where exactly is that trade-off worth making? I care about getting these ideas past the paper stage, into code that is documented and genuinely usable in bioinformatics practice.

Research

Three threads, all variations on the same theme: represent a collection of similar sequences compactly, then show what you can still answer from the compressed representation — and at what cost.

Data structures in taxonomic classification

Published · SEA 2024 FM-index Maximal exact matches Lossy compression

In taxonomic classification we index the genomes in a phylogenetic tree so that, given a DNA read, we can quickly pick a small subtree likely to contain the genome the read came from. Popular classifiers such as Kraken use k-mers, but recent work indicates that maximal exact matches (MEMs) give better classifications. The MEM-based recipe is:

  1. build an augmented FM-index over the genomes in the tree, concatenated in left-to-right order;
  2. for each MEM in a read, find the suffix-array interval holding the starting positions of that MEM's occurrences;
  3. find the minimum and maximum values stored in that interval;
  4. take the lowest common ancestor (LCA) of the genomes containing the characters at those positions.

That is practical only while the total size of the genomes stays fairly small. We asked what happens if the same recipe runs over a lossily compressed concatenation instead, using three representations:

  • a KATKA kernel, which discards characters that are not in the first or last occurrence of any kmax-tuple, for a parameter kmax;
  • a minimizer digest;
  • a KATKA kernel of a minimizer digest.

With a test dataset, simulated reads and a sweep over the parameter settings, we measured how many reads' longest MEMs occurred only in the sequences the reads were generated from (the "true positive" reads). For some settings we achieved significant compression while the true-positive rate dropped only slightly.

Elastic-degenerate strings for pangenomes

Ongoing Pangenomics EDS Reference-free representation

Genomic data can be stored in many formats, from a plain collection of raw sequences to variant calling formats (VCFs), which record more sophisticated information about individual variants. Most of these formats still compare every new sequence against a reference, which limits the analysis to a consensus established from limited information. That is one reason elastic-degenerate strings (EDS) have found a place in pangenomics.

An EDS retains information from all the sequences in a collection at a reasonable reduction in memory, so it stays representative of the species' pangenome. Depending on whether we keep the phasing of the original sequences, we can even predict variants that have not yet been added to the collection.

The construction process is the crux: there are many ways and many parameters, and they strongly influence the information capacity, the size, and the compression ratio of the resulting structure.
